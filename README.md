# Numerical companion: FLRW curvature, boundary pinning, and the $S^3$ sphaleron

This repository contains the numerical material accompanying the manuscript

**R. Majid Zonoozi and M. Nadjafikhah, _Spatial curvature, boundary pinning and the $S^3$ sphaleron: the Hessian spectrum of $\phi^4$ interfaces in Friedmann–Lemaître–Robertson–Walker spacetimes_.**

The code implements the radial boundary-value problems, reduced Hessian spectra, Morse-index diagnostics, robustness checks, dynamical mode evolution, and the regular-wall/sphaleron calculation reported in the manuscript. The numerical workflow is deterministic and uses only NumPy, SciPy, and Matplotlib.

## Repository contents

This repository contains exactly two files, matching the code-availability statement in the manuscript:

- `flrw_numerics.py` — a flat-space Bogomolny infrastructure check, boundary-pinned FLRW profiles, reduced Hessian spectra, curvature/box checks, robustness diagnostics, dynamical relaxation, and Figures 1–3.
- `wall_numerics.py` — regular unpinned walls, the no-go calculation on $\mathbb{R}^3$ and $H^3$, the $S^3$ existence threshold, sphaleron spectrum, and Figure 4.

Every figure in the manuscript is produced with Python (Matplotlib) by these scripts, and every number quoted in the manuscript tables is regenerated deterministically by them. No external research dataset is required and no random seeds are involved.

## Scientific scope

For the three maximally symmetric FLRW spatial sections,

$$
\Sigma_k \in \{S^3,\mathbb{R}^3,H^3\}, \qquad k\in\{+1,0,-1\},
$$

the scalar potential is

$$
V(\phi)=\frac{\lambda}{4}(\phi^2-v^2)^2.
$$

The main pinned calculation solves the geodesic-radial field equation

$$
\phi''+2\,\operatorname{ctn}_k(\chi)\phi'=V'(\phi),
$$

with the boundary prescription used in the manuscript, and diagonalizes the reduced fluctuation operator

$$
\mathcal H_j^{(k)}
=-\frac{d^2}{d\chi^2}+V''(\phi_0)-\frac{k}{a^2}
+\frac{j(j+1)}{S_k^2(\chi)}.
$$

At the benchmark point $\lambda=v=a=1$, eigenvalues of the pinned problem are reported in units of $\lambda v^2$ (which equals $a^{-2}$ there).

In `wall_numerics.py` the coupling $\lambda$ varies along the tables, so the two units no longer coincide and eigenvalues are reported in units of $a^{-2}$. A quick check of that convention: since $\mathcal H_{j=2}-\mathcal H_{j=1}=4/\sin^2\chi\ge4$ and $\lambda_{\min}^{(j=1)}=0$, the exact bound $\lambda_{\min}^{(j=2)}\ge4$ must hold, and the printed values do satisfy it.

The second calculation removes the inner pinning condition and tests whether globally regular static interfaces exist. It verifies the noncompact virial obstruction and resolves the regular equatorial wall on $S^3$ when the dimensionless coupling satisfies

$$
\lambda v^2 a^2>3.
$$

Its fluctuation spectrum establishes the sphaleron character of that wall: one negative $j=0$ mode, a threefold $j=1$ zero-mode kernel generated by isometries, and positive $j\ge2$ sectors.

## Numerical method

The pinned static profiles are computed with `scipy.integrate.solve_bvp`. The reduced Hessian is represented by a second-order finite-volume/finite-difference quadratic form on a uniform radial grid. Dirichlet boundary nodes are eliminated exactly. After removal of the diagonal mass matrix by a symmetric similarity transformation, the problem is real, symmetric, and tridiagonal; the requested low-lying spectrum is obtained with `scipy.linalg.eigh_tridiagonal`.

For the benchmark pinned calculation the defaults are

```text
N = 500
L = 8
chi_min = 1e-3
lambda = v = a = 1
```

The Morse index is the number of eigenvalues below `-1e-8`.

The unpinned $S^3$ wall is obtained by regular shooting on one hemisphere and antisymmetric extension across the equator. Its low-lying fluctuation spectrum is again computed as a symmetric tridiagonal eigenproblem.

## Reproducing the pinned FLRW results

Run

```bash
python flrw_numerics.py
```

The run opens with a flat-space validation of the discretization against the exact Bogomolny energy $2\sqrt2/3$,

```text
Bogomolny bound: numerical 0.942809, exact 0.942809, relative error 2.7e-09
```

The benchmark spectrum (Table 4 of the manuscript) should include

| Section | $k$ | $\lambda_{\min}$ | $\lambda_2$ | Morse index | $\lambda_{\min}^{(k)}-\lambda_{\min}^{(0)}$ |
|---|---:|---:|---:|---:|---:|
| $S^3$ | +1 | 1.999 | 5.002 | 0 | -0.155 |
| $\mathbb{R}^3$ | 0 | 2.154 | 2.617 | 0 | 0.000 |
| $H^3$ | -1 | 3.154 | 3.617 | 0 | +1.000 |

The default run also prints the angular-sector check, the Dirichlet-box approximation, the robustness table, cutoff dependence, collapse of the pinned layer as $\chi_{\min}\to0$, and the reduced dynamical-mode evolution.

For the extended numerical validation used in the manuscript, run

```bash
python flrw_numerics.py --full-validation
```

This additionally evaluates grid convergence, ground-mode overlaps with the corresponding Dirichlet box modes, and the one-parameter-at-a-time robustness scan. This mode is intentionally more computationally demanding than the benchmark run.

To regenerate Figures 1–3,

```bash
python flrw_numerics.py --figures
```

which writes

```text
figs/flrw/fig1_profiles.pdf
figs/flrw/fig2_spectrum.pdf
figs/flrw/fig3_dynamics.pdf
```

## Reproducing the unpinned-wall and sphaleron results

Run

```bash
python wall_numerics.py
```

The calculation performs three independent checks.

### 1. No regular interpolating wall on $\mathbb{R}^3$ or $H^3$

The shooting scan is consistent with the virial identity

$$
V(\phi(0))+
\int_0^\infty 2\,\operatorname{ctn}_k(\chi)(\phi')^2\,d\chi=0,
$$

whose terms are non-negative for $k=0,-1$. Consequently a nontrivial regular static interpolation is excluded on both noncompact sections.

### 2. Existence threshold on $S^3$

The code resolves the bifurcation of the equatorial wall at

$$
\lambda v^2a^2=3.
$$

Representative output is

| $\lambda v^2a^2$ | wall | $\phi_0(0)/v$ |

| 3.20 | yes | -0.349975 |

## Reproducibility status

Fresh executions of the two reference scripts reproduce the benchmark numerical results reported above and agree with the corresponding tables and numerical statements of the manuscript to the displayed precision.

The distinction between invariant conclusions and convention-dependent quantities is essential:

- the vanishing constrained Morse index in the tested pinned configurations is robust;
- the ordering $\lambda_{\min}^{(S^3)}<\lambda_{\min}^{(\mathbb R^3)}<\lambda_{\min}^{(H^3)}$ is preserved in the reported robustness tests;
- the noncompact curvature gap is fixed by the common-profile shift, while individual finite-box eigenvalues depend on the cutoff and boundary convention;
- the unpinned $S^3$ wall has Morse index exactly one; this is proved in the manuscript from reflection parity and Sturm oscillation, and the runs realize it;
- the unpinned $S^3$ wall and the boundary-pinned layer belong to different configuration classes, interpolating $-v\to+v$ and $0\to+v$ respectively, so their Morse indices should not be matched mode by mode.

These distinctions should be preserved when using the code or quoting its numerical output.
